# Code of Conduct

## Our Standards

We expect contributors and maintainers to:

- be respectful and professional
- assume good intent while staying direct and factual
- focus criticism on ideas, code, and process rather than people
- protect sensitive user and operational data when discussing bugs or incidents

Unacceptable behavior includes:

- harassment, insults, or discriminatory language
- publishing private information without consent
- posting sensitive logs, credentials, or chat data in public threads
- disruptive behavior that blocks constructive collaboration

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and related project communication.

## Reporting

If you experience or witness unacceptable behavior, contact the repository maintainers through GitHub.

If the report also involves a security issue or sensitive data exposure, follow `SECURITY.md` and avoid posting the details publicly.
